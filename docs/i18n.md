# 界面语言（i18n）

BatteryHub 的界面（状态面板 / 托盘菜单 / 气泡通知 / 关于框 / 配置文件注释）和命令行输出
（`--help`、`--once`、`--dump`、`--sysmon`、`--watch`、`--capture-report`）都支持 10 种语言。
默认**跟随 Windows 的界面语言**，也可以在托盘菜单里手动指定。

## 支持的语言

| 语言 | 配置值 | 面板字体 |
|---|---|---|
| English | `en` | Segoe UI |
| 简体中文 | `zh-CN` | Microsoft YaHei UI |
| 繁體中文 | `zh-TW` | Microsoft YaHei UI |
| 日本語 | `ja` | Yu Gothic UI |
| 한국어 | `ko` | Malgun Gothic |
| Deutsch | `de` | Segoe UI |
| Français | `fr` | Segoe UI |
| Español | `es` | Segoe UI |
| Русский | `ru` | Segoe UI |
| Português (Brasil) | `pt-BR` | Segoe UI |

未支持的系统语言（如 cs-CZ、tr-TR）回落英文，不会出现半截中文。

## 怎么选（优先级从高到低）

1. **托盘右键 → 语言**：点一条立即生效（菜单、面板、通知、关于、`--help` 都跟着变），并写回配置。
   第一项是「跟随系统」。
2. **`config.ini` 的 `[ui] lang=...`**：`auto`（默认）或上表的配置值；`EN`、`zh_CN`、`pt` 这类写法也认。
3. 什么都没配 → 跟随系统。

系统语言取 `GetUserDefaultUILanguage()`——用户首选的**显示**语言（不是区域/格式），
中文再按子语言区分简繁：TW / HK / MO → 繁體，CN / SG → 简体。

## 老配置的迁移

v1.1.1 及以前没有语言菜单，`config.ini` 里写死的 `lang=zh-CN` 是默认值，不是用户的选择。
新版本第一次读到**没有 `[meta] schema` 标记**的配置、且 `lang=zh-CN` 时，会把它当成 `auto`
（老用户升级后也是“跟随系统”）；保存时写入 `[meta] schema=2`，此后用户明确选的 `zh-CN`
不会再被改回 `auto`。

## 加一种语言

1. `crates/bh-core/src/i18n/ui/<lang>.rs` 与 `crates/bh-core/src/i18n/cli/<lang>.rs`：
   各抄一份英文表，键必须一一对应（`ui` 表管界面，`cli` 表管命令行）。
2. 两个 `i18n/*/mod.rs` 里加 `pub mod <lang>;`；`i18n/mod.rs` 的 `Lang` 加一个枚举值，
   补齐 `tag` / `native_name` / `ui` / `cli` 四处 match 以及 `ALL`、`from_tag`、`from_langid`、`from_code`。
3. `crates/bh-app/build.rs` 的 `DESCRIPTIONS` 加一条（资源管理器「文件说明」用）。
4. `cargo test -p bh-core`：`i18n::tests` 会检查每个语言是否漏键、多键、占位符是否齐全。

## 边界

- **不翻译事实**：设备名/型号、VID/PID、温度、百分比、日志（`app.log`）保持原样；只翻标签。
- `--self-test` 的 `PASS` / `FAIL` 是机器可读输出，固定英文（CI 与脚本按它判）。
- `--once` 里的 `幽灵`（ghost）等排障标记会翻译，但 `usage=`、`bytes:` 这类报文格式不变。
- exe 的版本资源（属性 → 详细信息 →「文件说明」）按**系统语言**显示，与界面语言设置无关——
  资源管理器读不到应用的配置。
- 翻译文件是普通 Rust 静态表，没有运行时开销，也不引入任何第三方 i18n 依赖。
